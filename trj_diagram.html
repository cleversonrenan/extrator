📊 Diagrama Visual no Excel

O diagrama visual é gerado por um script Python que lê o estado atual do arquivo HTML (incluindo nodes expandidos, cores, anotações) e gera um .xlsx com boxes coloridos e conexões, idêntico ao que você vê aqui.

1 · Certifique-se de salvar o estado atual

Se o arquivo ainda não está conectado, clique em 🔗 Conectar Arquivo e faça uma alteração qualquer para que o estado seja gravado no HTML.

2 · Execute o script na pasta do arquivo
python gerar_diagrama_excel.py
O script está em: siteTRJ/gerar_diagrama_excel.py
O que é gerado: diagrama em árvore com boxes coloridos por status, linhas de conexão, fundo escuro, comentários Excel com anotações e rotas de cada site. O arquivo salvo será TRJ_Diagrama_YYYY-MM-DD.xlsx na mesma pasta.
